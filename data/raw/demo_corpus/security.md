# Security and Access

## Passwords
Use a unique password for each service and a password manager. Do not share passwords or store them in plaintext. Enable multifactor authentication whenever it is offered.

## Access requests
Request access through the designated access-request workflow. Requests must identify the system, requested role and business justification. Managers or system owners approve access based on least privilege.

## Security incidents
Report suspected security incidents promptly through the security incident reporting channel. Include a description, affected system and time observed when known. Do not attempt to investigate beyond actions needed to protect yourself or preserve evidence.

## Device handling
Use company-approved devices and keep operating systems and security updates current. Report lost or stolen devices promptly to IT and Security.
