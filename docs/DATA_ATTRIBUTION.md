# Data and attribution

## Bundled illustrative policies
The `data/raw/demo_corpus/` Markdown files were authored for PolicyPilot as fictional examples. They are not real employee policies, do not represent any company, and should only be used to smoke-test the project.

## GitLab Handbook (optional)
The GitLab Handbook is an optional external research corpus. Before fetching or redistributing it, inspect the exact license text in the repository, follow the attribution requirements, and record:
- retrieval date;
- repository commit hash;
- exact selected page list;
- license/terms reviewed;
- whether downloaded content is stored locally or redistributed.

The automated selector is heuristic and does not establish that a selected set is appropriate, complete, or licensed for redistribution. The project's GitHub repository intentionally does not include downloaded GitLab pages.
